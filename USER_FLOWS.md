# User flows

## Start and connect accounts

1. Complete passwordless email verification.
2. Connect the personal or work accounts you want to use.
3. Review permissions for each connection.
4. Choose Work or World mode for the current device.

## Handle email in Work mode

1. Switch to **Work mode**.
2. Open the **Email** tab.
3. Read, compose or send email manually when no assistance is needed.
4. When a message requires more work, delegate it to a Mind.
5. Ask the Mind to summarize, research, prepare a response or extract next steps.
6. Review the result before replying or continuing the work as a Task.

Minds do not each automatically receive an email address. Mail is a Work-mode surface that the user controls.

## Configure a Mind

1. Create or select a Mind.
2. Define its name, role, profile, voice and circle.
3. Add appropriate skills and apps.
4. Set an energy or budget limit.
5. Test a low-risk job before enabling broader access.

## Delegate work

1. Start from chat, an email in Work mode, dictation or voice.
2. Attach a Project and relevant files when context is needed.
3. State the outcome, deadline and approval boundaries.
4. Assign one Mind or several.
5. Follow the Taskboard; answer **Needs you**, review **Check it**, then mark **Done** or return feedback.

## Create a Project

1. Name the workstream and add private instructions.
2. Add source files.
3. Choose which Minds may use the context.
4. Start chats and Tasks inside the Project.
5. Review sources and access before sharing an output.

## Use a Multi-Mind Task

1. Create one clear objective.
2. Select two or more Minds.
3. Add an optional Project and due date.
4. Start the work.
5. Follow each Mind through its separate Task card.
6. Compare or combine the results.

## Enable and open Pods

1. Switch to **Work mode**.
2. Open **Settings**.
3. Expand **Experimental**.
4. Turn on **Pods**.
5. Close Settings.
6. Open Pods from the main sidebar or **More**.

Pods are experimental and the setting applies only to the current device.

## Turn discovery into a routine

1. Find an item in Discover.
2. Save it, choose **Ask a Mind** or select **Get this daily**.
3. Review the Task, schedule, responsible Mind and destination.
4. Preview the setup before activation.
5. Monitor the work through Tasks, the Dashboard and recaps; pause or edit when needed.

## Govern ongoing work

Check Mind status, energy, spend, daily or weekly recaps and memory. Pause a Mind, revoke an app, reduce a budget or disable an experimental feature when behavior no longer matches your expectations.
