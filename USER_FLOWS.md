# User flows

## Start and connect identities

1. Complete passwordless email verification.
2. Connect personal or work accounts.
3. Review permissions for each connection.
4. Choose default identity and send-as policy.

## Configure a Mind

1. Create or select a Mind.
2. Define name, role, profile, voice and circle.
3. Add skills and apps.
4. Set an energy/budget limit.
5. Test a low-risk job before enabling broader access.

## Delegate work

1. Start from chat, forwarded email, dictation or voice.
2. Attach a project and relevant files.
3. State outcome, deadline and approval boundaries.
4. Assign one Mind or several.
5. Follow the board; answer **Needs you**; review **Check it**; mark **Done** or return feedback.

## Create a project

1. Name the workstream and add private instructions.
2. Add source files.
3. Choose which Minds may use the context.
4. Start chats/tasks inside the project.
5. Review citations and access before sharing output.

## Turn discovery into a routine

1. Find an item in Discover.
2. Save it, ask a Mind or choose **Get this daily**.
3. Configure schedule, inputs, destination and owner.
4. Preview the first run.
5. Monitor in tasks/dashboard; pause or edit when needed.

## Govern ongoing work

Check agent status, energy/spend, daily/weekly recaps and memory. Pause a Mind, revoke an app or reduce budget when behavior drifts.
